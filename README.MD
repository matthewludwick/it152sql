# Team 8 Clinical IT Database

## Project Overview
In a busy hospital setting, clinical staff rely heavily on functioning technology to deliver effective patient care. Currently, the reporting of broken equipment and software is often fragmented, leading to long wait times for IT support and delayed response times. 

Our solution solves this problem by providing a centralized system to report, track, and manage IT support tickets. By streamlining the workflow between clinical staff reporting issues and the IT technicians resolving them, the database minimizes equipment downtime and improves communication. 

Ultimately, reducing technical downtime and analyzing recurring issues directly benefits hospital administrators, IT staff, and care providers. This efficiency cascades down to support the Triple Aim for Healthcare: enhancing the patient experience, improving population health, and reducing overall healthcare costs.

## How to Access
This repository contains a MySQL Workbench model file (`.mwb`) that represents the Entity-Relationship (ER) diagram and schema design. 

To open and view the database design:
1. Download and install [MySQL Workbench](https://dev.mysql.com/downloads/workbench/).
2. Open MySQL Workbench.
3. Go to **File** > **Open Model...** (or press `Ctrl+O` / `Cmd+O`).
4. Select the `.mwb` file included in this repository.
